# Arsenic_Adsorption_Notebook
Python framework for modeling, analyzing, and optimizing arsenic adsorption from water. Using Jupyter Notebook and non-linear regression, it automates data prep, evaluates kinetics, and fits 2/3-parameter isotherms (Langmuir, Freundlich, Sips, etc.). Includes data visualization to accelerate adsorbent screening and water treatment optimization.
